# Vex — แผนพัฒนา ส.ค. 2026 (เช็คลิสต์)

โจทย์จากเจ้าของ (4 ส.ค. 2026): ความจำสั้น · แจ้งงานไม่เป็นระเบียบ · ตีความคำสั่งพลาด · อ่านลิงก์/ไฟล์ไม่ลึก · คุมโซเชียล/เครื่องไม่ได้จริง · งานเบื้องหลังเงียบหาย

หลักการที่เจ้าของสั่ง: **ไม่ฟิกข้อมูล/ไม่ฟิกรูปแบบคำสั่ง — ให้ยืดหยุ่นอิสระเหมือนคุยกับ AI ทั่วไป เพียงแต่สวมบทเลขา**

การตัดสินใจที่ได้คำตอบแล้ว:
- โซเชียล = ทาง A (Chrome ตัวจริงของเจ้าของ + remote debugging port)
- เก็บลิงก์/รูปเข้าคลัง = **เฉพาะที่สั่งให้เก็บเท่านั้น** (ไม่สั่ง = อ่านให้ ตอบให้ แต่ไม่เขียนลงคลัง)
- โพสต์/ตอบโซเชียลแทน = ยืนยันทุกครั้ง + **แคปหน้าจอยืนยันว่าอยู่ที่โพสต์นั้นจริงและพิมพ์ค้างไว้พร้อมส่ง**

## Vex เข้า Discord — เลขาเสียงเปิดค้างทั้งวัน (เริ่ม 4 ส.ค. 2026)

โจทย์: Vex ตัวเดิม สมองเดิม ความจำเดิม ต้องมีอีกหนึ่งช่องทางคือ Discord · เจ้าของเปิดห้องเสียงค้างไว้ทั้งวันบนมือถือแล้วดับจอ คุยด้วยปาก และ Vex ต้องพูดขึ้นมาเองได้เมื่อมีเรื่องที่ควรรู้

หลักการที่ห้ามละเมิด: สมองเดียว ท่อหลายทาง (`/api/kiki/ingest` เป็นสมองเดียว ฝั่ง Discord เป็นแค่ท่อ) · ห้ามสร้าง DB/vault ที่สอง · เชิงรุกทุกตัวเริ่มจากปิดไว้ก่อน · ไม่แน่ใจ = เงียบ · ห้ามทำให้ Telegram พัง

### เฟส 0.5 เสร็จแล้ว — ตัวตนเดียว ผูกได้หลายบัญชี

**สิ่งที่พบตอนสำรวจ (ทำให้งานเล็กลงกว่าที่คิด)**
- `KikiChat` ไม่มีคอลัมน์ `chatId` มาแต่แรก → ประวัติเป็นสายเดียวรวมกันอยู่แล้ว ทักช่องไหนก็ต่อเรื่องเดิมได้ทันที ไม่ต้องรื้ออะไร
- `getKikiOwnerId()` มีจุดเรียกจริงแค่ 3 จุด ทั้งหมดอยู่ใน ingest

**ที่ทำจริง**
- `KikiChat.channel` (`telegram` | `discord` | `discord-voice` | `cron`) ดีฟอลต์ `telegram` — แถวเก่า 530 แถวได้ค่าครบ ไม่ต้อง backfill
- `kiki.ts`: `ownerAccounts()` / `isOwnerAccount()` / `linkOwnerAccount()` / `unlinkOwnerAccount()` เก็บที่ Setting `kiki_owner_accounts` = `["telegram:<id>", "discord:<id>"]` · seed อัตโนมัติจาก `kiki_owner_id` เดิมตอนถูกเรียกครั้งแรก · `getKikiOwnerId()` คงไว้ ของเดิมไม่พัง
- `issueLinkCode()` / `redeemLinkCode()` — รหัส 4 หลัก อายุ 10 นาที ใช้ครั้งเดียว ไม่มีเลขซ้ำติดกัน (อ่านออกเสียงได้ ไว้ผูกด้วยปากในเฟส 6)
- **เอา auto-bind "คนแรกที่ทัก = เจ้าของถาวร" ออก** เหลือเฉพาะกรณีระบบยังไม่เคยมีเจ้าของเลย **และ** มาจาก Telegram เท่านั้น → ช่องทางใหม่ตั้งตัวเองเป็นเจ้าของไม่ได้
- ช่องทางที่ยังไม่ผูก ตอบได้อย่างเดียวคือผลของการกรอกรหัส นอกนั้นเงียบสนิท
- ล็อกโหมดกลุ่มเทรนเนอร์อั๋นไว้เฉพาะ `platform === "telegram"` — กัน chatId ช่องทางอื่นชนแล้วทำ scope `aun` รั่ว
- `kikiConversation()` ติดป้ายสื่อเฉพาะช่องทางที่ไม่ใช่ telegram (`เจ้าของ (พูดในสาย Discord): ...`) ประวัติเดิมหน้าตาไม่เปลี่ยน

**เทสจริง 15 ข้อ ผ่านหมด** (ยิงเข้า `/api/kiki/ingest` ของจริง แล้วลบข้อมูลเทสออกทั้ง DB และเวกเตอร์)
- คนอื่นทักทาง Telegram / Discord = เงียบสนิท ไม่ถูกตั้งเป็นเจ้าของ · เดารหัสมั่วไม่ติด · รหัสผิดไม่ผูก · รหัสเดิมใช้ซ้ำไม่ได้
- พูดใน Discord ให้จำ → ถามต่อใน Telegram ตอบได้ และ Vex อ้างเองว่า "พี่บอกไว้เมื่อกี้ในสายเสียง Discord"
- Telegram เดิมครบ: การ์ดการเงิน · ตารางนัด · กระดานงาน · ความจำ · กฎที่สอนไว้ · คุยธรรมดา

**หนี้ที่ฝากไว้ให้เฟสถัดไป**
- `kiki_pending_dm` / `kiki_pending_social` ยังเป็นช่องเดียว ยังไม่ผูกกับช่องทาง — ต้องแก้ในเฟส 1 ก่อนเปิดใช้จริง ไม่งั้นสั่ง "ส่งเลย" ข้ามช่องทางแล้วส่งของผิดตัวออกไปในนามเจ้าของ
- `addKikiChatId()` ห้ามให้ท่อ Discord เรียก ไม่งั้น channel id ปนเข้ารายการที่ cron ใช้เป็นปลายทาง
- `sanitizeVexText()` แปลงเป็น HTML ของ Telegram — Discord ต้องมี renderer ของตัวเอง
- persona ยังเรียกเจ้าของว่า "พี่" สเปกใหม่ให้เรียก "โด้" — แก้ตอนทำเฟส 2

## บันทึกการทำงาน

**4 ส.ค. 2026 — เฟส 1 เสร็จ**
- `kiki-router.ts` ตัวจัดเส้นทางด้วย Gemini flash (~1.4 วิ/ครั้ง, Claude CLI สำรอง) แทน regex 25 จุดใน ingest — เทส 15 เคสจริงผ่าน 15/15 รวมเคสที่เคยพัง ("คิดชื่อกลุ่มให้หน่อย อยากได้..." เคยชน WISH_RE)
- `INTENT_CATALOG` เป็นแหล่งเดียวของทั้ง router และรายการความสามารถใน persona — เพิ่มความสามารถใหม่แก้ที่เดียว ไม่หลุด sync
- `kiki-tasks.ts` + model `KikiTask` — จด/ลิสต์/ปิด/ทวง + งานมีเงื่อนไข (triggerText) เตือนตอนเจ้าของพูดถึง
- `kiki-memory.ts` + ตาราง `kiki_recall` (sqlite-vec + bge-m3) — index แชท 397 ข้อความย้อนหลังแล้ว, recall ~0.4 วิ, สรุปรายวันเก็บใน `KikiMemory` (ไม่เขียนลง Obsidian ตามกติกาเก็บเฉพาะที่สั่ง)
- หน้าต่างบทสนทนา 18×500 → 40×1200 ตัวอักษร (เพดานรวม 20k)
- `kiki-format.ts` + เลิกซอยบับเบิลรายบรรทัด (สูงสุด 3 ก้อน) + บรีฟเช้าเขียนใหม่เป็นหัวข้อ/บรรทัดละรายการ
- heartbeat ทุก 3 นาทีของงาน Hermes/พัฒนา + ปุ่ม "หยุดงานนี้" · ตัวรันงานพัฒนาเปลี่ยนเป็น stream-json = รายงานได้ว่ากำลังแก้ไฟล์ไหน

**4 ส.ค. 2026 — เฟส 2 + เฟส 3 เสร็จ**
- `kiki-read.ts` ท่ออ่านเดียว: YouTube → ดูคลิปจริง · X/IG/FB/TikTok/LinkedIn → เปิดใน Chrome ที่ล็อกอิน · ที่เหลือ fetch แล้วถอยไปเบราว์เซอร์ถ้าเนื้อบาง · อ่านไม่ได้ = บอกตรง ๆ ห้ามเดา
- `summarizeLong` สรุปเอกสารยาวแบบไล่เป็นก้อน — เลิกตัดทิ้งที่ 24,000 ตัวอักษร
- ไฟล์ที่ส่งมา = อ่านลึกแล้วตอบ **แต่ไม่เก็บเข้าคลัง** ถ้าไม่ได้สั่ง (กติกาเจ้าของ)
- `kiki-chrome.ts` สะพาน CDP ไป Chrome ตัวจริง: `readUrl` (ข้อความ + แคปภาพ), `draftReply` (พิมพ์ค้างไว้ ไม่กดส่ง), `sendDraft` (กดส่งหลังยืนยัน), `discardDraft`, `socialLoginStatus`
  - Chrome 136+ ห้าม remote debugging บนโปรไฟล์ Default → ใช้โปรไฟล์แยก `~/.vex-chrome` เปิดด้วย `npm run kiki:chrome`
  - เทสแล้ว: ต่อ CDP ได้ · อ่าน x.com ได้จริง 1,923 ตัวอักษร + แคปภาพ (ยังไม่ล็อกอิน = ยังอ่านโพสต์ส่วนตัวไม่ได้)
- `KikiMedia` + `kiki-media.ts`: เก็บรูป/วิดีโอ **เมื่อสั่ง** → วิชันบรรยายเนื้อในรูป → ค้นคืนด้วยความหมาย (เทสจริงผ่าน: เก็บ → ขอคืน → ได้ไฟล์ถูกตัว) · บอทรับวิดีโอ/GIF แล้ว
- ตอบรายการเงินรอระบุทีเดียวหลายตัว (`classifyPendingBatch`) + ขอลิสต์เต็มได้ทุกเมื่อ
- คุม Mac: ระบบตรวจเองว่ามีไฟล์ภาพจริงไหม ถ้า AI เคลมว่าแคปแล้วแต่ไม่มีไฟล์ = ต่อท้ายคำเตือนจากระบบ

**4 ส.ค. 2026 — เฟส 4 เสร็จ**
- `kiki-advice.ts` โหมดที่ปรึกษาการเงิน: เจ้าของเล่ารายละเอียดยาว ๆ → วิเคราะห์จากตัวเลขจริงในระบบ (งบ/หนี้/บิล/pace) → จำข้อเท็จจริงการเงินถาวร + ลงงานที่ต้องทำเข้ากระดานอัตโนมัติ + เก็บ "แผน" ไว้เทียบทีหลัง
- รายงานอาทิตย์เย็นเพิ่มหัวข้อ "รีวิวเทียบแผน": ทำตามแผนได้กี่ข้อ ค้างอะไร ต้องแก้อะไรสัปดาห์หน้า

- **บั๊กที่เจอระหว่างกวาด: ตัวตัดคำไทยพังทั้งระบบ** — `[^\p{L}\p{N}\s]` ลบสระ/วรรณยุกต์ (Unicode Mark) ทิ้ง ทำให้ "ขอรูปตอนไปเที่ยวทะเล..." กลายเป็นเศษ ["ขอร","ปตอนไปเท","อย"] แล้ว "อย" ไปแมตช์ข้อความอื่นมั่ว
  - แก้เป็น `\p{M}` ครบทุกจุด (kiki.ts / kiki-tasks.ts / kiki-media.ts) + ขั้นต่ำ 3 ตัวอักษร + ต้องได้คะแนน ≥3 ถึงนับว่าเกี่ยว
  - กระทบตั้งแต่ค้นโน้ตส่วนตัว ค้นรูป หางานในกระดาน ไปจนถึงเงื่อนไขเตือน — ทั้งหมดเคยจับมั่วได้
