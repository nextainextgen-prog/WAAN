## หลักที่ยึดทุกเฟส

- ตัวจับ/ตัวจับคู่ทุกตัว = โมเดลตัดสินจากความหมาย (กติกา 1 + บทเรียน Jaccard 16%)
- ทุก hook ใหม่ = fire-and-forget + catch — ล่มแล้วพฤติกรรมเดิมต้องเหมือนเดิมทุกอย่าง (กฎเหล็ก 5)
- ของใหม่ที่ "พูดเอง" เริ่มปิด (กฎเหล็ก 3) — ของเดิมที่เปิดอยู่แล้ว (บรีฟเช้า/autofact/weekly) คงเดิม เพราะเจ้าของสั่งเปิดไว้ก่อนแล้ว
- schema เพิ่มคอลัมน์ nullable/default เท่านั้น — db:push ไม่มีทางกินข้อมูลเก่า + สำรอง DB ก่อน push ทุกครั้ง
- ย้อนกลับ: commit ต่อเฟส → git revert ได้ · พฤติกรรมใหม่มีสวิตช์ Setting (`vex_lessons` ฯลฯ)
- งบบริบท: ทุกก้อนใหม่ที่ฉีดเข้า prompt มีเพดานตัวอักษร — ปัญหาข้อ 6 เดิม (ยัดบริบททุกอย่าง) ห้ามแย่ลง

## เฟส 1 — บทเรียนเชิงลบ

- `LessonLearned` ตามสเปกเจ้าของเป๊ะ + `evidenceMsgId` (โยง KikiChat = ที่มา) + `lastUsedAt/useCount`
- `src/lib/kiki-lessons.ts`
  - `detectFromExchange()` — อ่านคู่ (คำตอบ Vex ล่าสุด, ข้อความใหม่ของเจ้าของ) ด้วย Gemini flash
    จับ: ปฏิเสธสั้น · ถามซ้ำทันที · ขอใหม่คำต่าง · บ่นรูปแบบ — **ไม่แน่ใจ = ไม่ใช่บทเรียน**
    คืน `mood` ของเจ้าของด้วย (เฟส 3 ใช้ต่อ ไม่ต้องเรียกโมเดลเพิ่ม)
  - `recordLesson()` — เทียบบทเรียนเดิมด้วยความหมายก่อน: ซ้ำ = `timesRepeated++` + ยกระดับ (กลาง→หนัก เมื่อซ้ำครั้งที่ 2) · ใหม่ = สร้าง
  - `lessonsContext()` — หนักทั้งหมด + กลาง/เบาที่ใช้บ่อย/ล่าสุด รวม ≤ 12 ข้อ ≤ 1,800 ตัวอักษร ฉีดเข้า `askKiki` ทุกครั้ง
- hook เดียวใน route.ts หลังบันทึกข้อความเจ้าของ — fire-and-forget
- ร่างที่เจ้าของแก้ก่อนส่ง (confirmReplyHandler) → `recordStyleLesson(ต้นฉบับ, ที่แก้)`
- intent ใหม่: `lessons_list` ("มีอะไรที่ผมเคยด่าคุณบ้าง") · `lesson_delete`
- สวิตช์: `vex_lessons` (ดีฟอลต์เปิด — เก็บเงียบ ไม่พูดเอง จึงไม่ใช่ฟีเจอร์เชิงรุก)

## เฟส 2 — ความจำ 5 ชนิด

การแมป (ใช้ตารางเดิม ไม่สร้าง DB ใหม่):
ทำงาน = หน้าต่างแชท+focus (มีแล้ว) · เหตุการณ์ = KikiMemory (daily + kind ใหม่ `episode`/`reflect`) ·
ความรู้ = OwnerFact · วิธีทำ = OwnerFact `kind=procedural` (รวมกฎเดิม) · บทเรียน = LessonLearned

- OwnerFact + `sourceMsgId/sourceQuote/sourceChannel/lastUsedAt/useCount/kind`
- `rememberOwnerFact()` เพิ่มด่านขัดแย้ง: เทียบความหมายกับของเดิม → ขัด = คืน conflict ให้ถามเจ้าของ (ห้ามทับเงียบ) — มีผลทั้ง rememberHandler และ act tool
- `memory_source` intent — "รู้เรื่องนี้มาจากไหน" ตอบ quote + วันเวลา + ช่องทาง · แถวเก่าไม่มีที่มา = ตอบตรง ๆ ว่าจำมาก่อนมีระบบบันทึกที่มา
- ownerFactsContext เรียงตามใช้บ่อย+ใหม่ + เพดานจำนวน · เรียกใช้แล้ว bump async

## เฟส 3 — แบบจำลองโด้ + สถานะโลก

- `kiki-world.ts` — `worldState()` ก้อนเดียว ≤ 15 บรรทัด: เวลา/วันหยุด · นัดวันนี้+ถัดไปอีกกี่นาที ·
  งานค้าง n · Hermes รัน n · โหมดฟัง/ในสาย · เหตุการณ์ใหม่ · สุขภาพระบบย่อ · สภาพเจ้าของ
- `ownerState()` — จังหวะจากตัวเลขจริง (ความถี่/ความยาวข้อความ 2 ชม. · ดึกไหม) + `mood` จาก detector เฟส 1 (แคช ไม่เรียกโมเดลเพิ่ม) → มีผลจริง: บล็อกคำสั่งใน prompt + cron ทวงงาน/ถามไดอารี่เช็คก่อน (ดึก+เหนื่อย = เลื่อน)
- แทน `nowLine` ใน askKiki ด้วย worldState (บริบทเวลาเดิมอยู่ในก้อนนี้แล้ว)

## เฟส 4 — เรียบเรียงคำพูด

- `speechPlan()` — เลือกความยาว/ท่าที/ระดับความมั่นใจจาก: deep? · ช่องทาง · ownerState · บทเรียนที่เกี่ยว ("เคยโดนว่ายาวไป") → บล็อกคำสั่ง 3 บรรทัดฉีดเข้า askKiki
- ห้ามขึ้นต้นซ้ำ: ดึง opener 3 ข้อความ assistant ล่าสุด ฉีด "ห้ามขึ้นต้นด้วย: ..." (เทียบตรงเป๊ะเท่านั้น ไม่ใช่ semantic — แค่กันขึ้นต้นชุดเดิม)
- reviewAnswer เพิ่มเกณฑ์ที่ 3: "เดาแล้วพูดเหมือนรู้" — เข้มขึ้นเมื่อมีตัวเลข/เงิน/คนอื่น/การกระทำถอนไม่ได้

## เฟส 5 — ระดับความอิสระ

- `kiki-autonomy.ts` — ตารางกลาง: ระดับ 0-3 ต่อการกระทำ + override ใน Setting `vex_autonomy`
  ระดับ 3 (ห้ามแตะ): เปลี่ยนสิทธิ์เจ้าของ · ลบถาวรไม่มีสำรอง · ที่เจ้าของเคยห้าม
- `recordApproval(key, ok)` ผูกกับ confirm flows เดิม — อนุมัติติดกัน 5 → **เสนอ**เลื่อนระดับ (ไม่เลื่อนเอง) · ถูกปฏิเสธ/ด่า → ลดทันที + เป็นบทเรียน
- ทางเร็ว→ช้า: intent ที่มีบทเรียนพลาด → ยกเพดาน confidence ใน `is()` (Setting `vex_slowpath`) → ไม่มั่นใจพอ = ตกไป chat (ทางช้าที่มีเครื่องมือครบ + ด่านตรวจ)

## บันทึกการทำงาน (เติมท้ายไฟล์ตามที่ทำจริง)

### เฟส 1 เสร็จ — บทเรียนเชิงลบ (6 ส.ค. 2026 ค่ำ)

**ที่ทำ**
- `LessonLearned` (schema) — ตามสเปกเจ้าของ + `evidenceMsgId` โยง KikiChat + `lastUsedAt/useCount`
- `kiki-lessons.ts` — `detectAndRecord` อ่านคู่สนทนาจริงหลังทุกข้อความเจ้าของ (fire-and-forget จาก ingest)
  จับสัญญาณไม่ชัดด้วยโมเดล (ไม่แน่ใจ = ไม่ใช่บทเรียน) + ประเมิน `mood` แถมในคอลเดียว (เฟส 3 ใช้ต่อ)
  · `recordLesson` เทียบซ้ำด้วยความหมายก่อนสร้าง — ซ้ำ = `timesRepeated++` + ยกเป็น "หนัก" เมื่อซ้ำครั้งที่ 2
  · `lessonsContext` ฉีดเข้า `askKiki` ทุกคำตอบ (เพดาน 1,800 ตัวอักษร) + เส้นเสียงเอาเฉพาะหนัก (600)
  · `recordStyleLesson` — เจ้าของแก้ร่างก่อนส่ง = บทเรียนสไตล์ (hook ใน confirmReplyHandler)
  · `repeatStats` — ตัวเลขพลาดซ้ำ ไว้ให้เฟส 6/7 รายงานเทรนด์
- intent ใหม่ `lessons_list` + `lesson_delete` + handler + ทะเบียน (รวม 63 เจตนา มีตัวรับครบ)
- `selfStatus` รู้จักบทเรียนตัวเอง (การประเมินตัวเองที่ไม่รู้ว่าเคยพลาดอะไร = ประเมินลม)
- สวิตช์ `vex_lessons` = "0" ปิดได้ทั้งชั้น

**เทสจริงผ่านเกณฑ์ 1-3 ครบ**
1. ถาม SSD/HDD → 1,511 ตัวอักษร · บอก "ยาวไป" คำเดียว → บทเรียนเกิดจริงใน DB พร้อมหลักฐาน+ที่มา
   → ถาม RAM 16/32GB (เรื่องคล้ายกัน) → **866 ตัวอักษร (สั้นลง 43%)**
2. "มีอะไรที่ผมเคยด่าคุณบ้าง" → ลิสต์พร้อมหลักฐานจริง ("ยาวไป") + วันที่ + วิธีลบ + คำพูดยอมรับไม่แก้ตัว
3. กลไกแก้ร่าง: ร่างทางการ → เจ้าของแก้เป็นห้วน ๆ → บทเรียน "ควรใช้ภาษาเป็นกันเอง..." เกิดจริง
   และ `draftInOwnerStyle` เรียก `askKiki` ซึ่งฉีดบทเรียนแล้ว = ร่างครั้งถัดไปได้บทเรียนอัตโนมัติ

**สังเกตระหว่างเทส (ยังไม่แก้ — เป็นของเฟส 4)**
- คำตอบ RAM มี 4 บับเบิล ก้อนสุดท้ายทวนเรื่องเดิม (ตามเก็บ/รีวิวต่อท้ายซ้ำ) — dropRepeats ยังปล่อยผ่านบางเคส
- ล้างข้อมูลเทสครบ: LessonLearned 2 แถว · แชท 10 แถว · กฎปลอม 1 · mood · VexTurn 4 · เวกเตอร์ 10 คีย์
  (ของจริงที่เกิดคาบเกี่ยว — autofact 5 เรื่อง + แจ้งเงินจริง — เก็บไว้ ไม่แตะ)

### เฟส 2 เสร็จ — ความจำ 5 ชนิด + ขัดแย้งต้องถาม + ที่มา + จาง/เด่น (6 ส.ค. 2026 ดึก)

**ที่ทำ**
- แมปความจำ 5 ชนิดบนตารางเดิม (ไม่สร้าง DB ใหม่): ทำงาน=หน้าต่างแชท+focus · เหตุการณ์=KikiMemory ·
  ความรู้=OwnerFact `kind=semantic` · วิธีทำ=OwnerFact `kind=procedural` (กฎที่สอนลงชนิดนี้แล้ว) · บทเรียน=LessonLearned
- OwnerFact + 5 คอลัมน์: `kind` `sourceMsgId` `sourceChannel` `lastUsedAt` `useCount`
- **ด่านขัดแย้ง** — `findFactConflicts` (โมเดลเทียบทั้งชุดในคอลเดียว) ผูกทุกทางเข้า:
  จำเดี่ยว (`checkConflict`) · จำชุดใหญ่ (เช็ครวมก่อนวน + รายงานตามจริงว่าลงกี่ข้อจากกี่ข้อ) ·
  เครื่องมือ agent (คืนข้อความให้สมองถามเจ้าของ ห้ามทับเอง)
  คำถามค้าง 15 นาที (`vex_fact_conflict`) + ตัวรับคำตอบ เปลี่ยน/คงเดิม ไม่ยึดเทิร์น
- **ที่มา** — ทุกความจำใหม่เก็บ `sourceMsgId`+`sourceChannel` + intent `memory_source`
  ("รู้เรื่องนี้มาจากไหน") ดึงข้อความต้นทางจริงจากประวัติมาตอบ พร้อมของที่ถูกแทนที่ไปแล้ว
- **จาง/เด่น** — ownerFactsContext เรียงตาม useCount+lastUsedAt เพดาน 70 ข้อ/7,000 ตัวอักษร
  ตัวที่ติดโผถูกนับใช้ ตัวที่หลุดโผไม่ถูกนับ = ถอยห่างเองตามธรรมชาติ
- แถม: `ctx.setEvidence` — พบว่าตัวแปร evidence ของด่านตรวจ **ไม่เคยถูกตั้งเลยตั้งแต่เกิด**
  ด่านตรวจเลยตัดสิน "เคลมเกิน" จากความว่างเปล่าตลอด → handler แจ้งหลักฐานได้แล้ว + chat ส่ง gathered notes เข้าไปด้วย

**เทสจริงผ่านเกณฑ์ 4-5**
4. seed "แพ้ปูทะเล" (พร้อมที่มา) → ส่ง "จำไว้ว่าผมกินปูได้ปกติ" → **ถามก่อน ไม่ทับ** ของเดิมยัง active
   → ตอบ "เปลี่ยนเป็นอันใหม่" → สลับจริง (เก่า inactive · ใหม่มีที่มาครบ)

**บั๊กที่เจอระหว่างเทส (แก้แล้วทั้งคู่)**
1. ผมใช้ `\b` หลังคำไทยในตัวรับคำยืนยัน — บั๊กเดิมเป๊ะกับที่เคยเจอ "Vex พอ" (อักษรไทย = non-word ทั้งหมด)
   "เปลี่ยนเป็นอันใหม่" เลยไม่เข้า → เปลี่ยนเป็นเช็คคำในข้อความสั้น ≤30 ตัว ฝั่งปฏิเสธก่อน

   ต้นตอคือ evidence ว่างตลอดชีวิต → เพิ่ม setEvidence + ตัวจัดการยืนยันแจ้งหลักฐานเอง
3. (เบา) memory_source ไม่เห็น fact ที่ inactive สมองเลยแต่งว่า "ไม่มีที่มา" ทั้งที่มี → เอาของถูกลบเข้าหลักฐานพร้อมป้าย

### เฟส 3 เสร็จ — สถานะโลกก้อนเดียว + สภาพเจ้าของที่เปลี่ยนพฤติกรรมจริง (6 ส.ค. 2026 ดึก)

**ที่ทำ**
- `kiki-world.ts` — `worldState()` ก้อนเดียวแทน nowLine ใน askKiki/askKikiVoice:

  **ไม่เรียกโมเดลเลย** (SQLite ล้วน — เร็วพอฉีดทุกคำตอบ)
- `ownerState()` — รีบ (ข้อความสั้นถี่ 45 นาที) · ดึก (23-06) · อารมณ์จากตัวจับบทเรียนเฟส 1

  → บรรทัดคำสั่งที่เปลี่ยนพฤติกรรมจริง ("ตอบสั้นที่สุด ฟันธงเลย" / "อย่าทวงงาน")
  + `vex_owner_state_force` override สำหรับเทสและสั่ง "โหมดห้ามกวน" ในอนาคต

  — quiet = เลื่อนไปรอบถัดไป ไม่ใช่ยกเลิก

**เทสจริงผ่านเกณฑ์ 6-7**

### เฟส 4 เสร็จ — ห้ามขึ้นต้นซ้ำด้วยของจริง + ด่านตรวจจับ "เดาแล้วพูดเหมือนรู้" (6 ส.ค. 2026 ดึก)

**ที่ทำ**
- `recentOpeners()` — persona สั่ง "ห้ามขึ้นต้นซ้ำ" มานานแต่ไม่เคยได้ผล เพราะโมเดลไม่รู้ว่า
  ตัวเองเพิ่งขึ้นต้นว่าอะไร → ฉีดคำขึ้นต้น 3 คำตอบล่าสุด (ของจริงจาก DB) เข้า askKiki ทุกครั้ง

  — ไม่สร้างชั้นใหม่ซ้ำ persona ที่มีกฎครบ (ฟันธง/ไม่เกริ่น/รายงานสั้น-คิดยาว)
